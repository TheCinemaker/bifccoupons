# Workspace Rules

- **NO EMOJIS AT ALL**: Never use any emojis in UI text, code, template strings, canvas overlays, or agent responses. Keep all text strictly clean without emoji characters.
- **STRICT BRAND NAME FORMAT**: The brand name MUST ALWAYS be written as a SINGLE WORD without spaces, in ALL CAPS: **KINABOLVEDDMEG** (or **KÍNÁBÓLVEDDMEG**). Never split into separate words.
